## Maintenance

### Adding New Documents
1. Create file in appropriate directory
2. Update this manifest
3. Update `INDEX.md`
4. Update `README.md` if needed

### Updating Existing Documents
1. Edit the document
2. Update `COMPLETION-SUMMARY.md` if status changes
3. Update `INDEX.md` if navigation changes

### Resolving Gap Reports
1. Review gap report
2. Make decision on standard
3. Update or create document
4. Move gap report to `gap-identification/reports/`
5. Update `COMPLETION-SUMMARY.md`
