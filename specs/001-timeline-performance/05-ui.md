This spec is a performance fix, not a redesign. The mockup intentionally keeps
the existing card look (owned by Spec 002) and only shows the three things
this spec changes behaviorally: the skeleton loading state, the Event-radius
slider, and cursor-based "load more" paging.

## New patterns proposed

**Skeleton loading via Livewire `#[Lazy]` + `placeholder()`.** Today
`NearbyFeed::mount()` blocks the whole page until the feed query returns, so
the user sees a blank page (confirmed in `01-archaeology.md`). This spec makes
`NearbyFeed` lazy-loaded (Livewire 3.x, https://livewire.laravel.com/docs/3.x/lazy)
and adds a `placeholder()` that renders a pulsing skeleton matching the card
grid shape. This is the first skeleton pattern in the app — propose adding it
to `docs/UI_STANDARDS.md` §5 (states and feedback) at Freeze as the standard
"loading" treatment for any lazy-loaded feed/list component, rather than a
one-off for this feature.
