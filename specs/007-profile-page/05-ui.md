## Deviations from the mockup

- Success toasts for follow, unfollow and remove are not built. The state change is visible in place.
- Rows use the event cover image when one exists; otherwise a gradient with an icon (the mockup used emoji for every row).
- Event rows with status `cancelled` show a "Cancelled" badge instead of Upcoming/Past (owner only; other viewers never see them).

- 2026-10-22 (owner, post-approval): the header stats row drops "posts" (the Posts tab already shows the count), leaving followers and following. The fourth tab is renamed "Saved Posts". Mockup updated to match.
