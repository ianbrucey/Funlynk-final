Follower and following lists — mockup

Spec 011 (placeholder number) · Status: DRAFT · Tracker item P1 · Synthetic data only · 390px phone first, then desktop. Interactive.

What this proposes (all [P]): (1) The followers and following counts in the profile header become links (shown as the first block). (2) One list page with a Followers | Following switch, each side showing its count. Routes /u/{username}/followers and /following. (3) Each row: avatar, name, @handle, location, and a named Follow / Following pill (none on your own row). Tapping the name opens the profile. (4) Newest first, 20 per page with "Load more". (5) Locked profiles show the same lock message as the profile tabs, with no rows. (6) Empty states differ for the owner and for visitors. (7) Search box under the switch filters the list you are on by name or @handle; no match shows a clear-search state. Switching tabs clears it.
