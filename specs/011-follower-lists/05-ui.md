## Deviations from the mockup

- The Followers | Following switch is two links (separate URLs) rather than one in-page toggle, so each tab has its own address and clears the search.
- Success toast uses the app's existing toast; the follow pill is the same as on feed cards.
- Only the profile header's mobile stats row exists in the built profile (the redesign shows one row at every width), so there is one pair of links, not two.

## New patterns proposed

- None. Reuses the segmented switch (spec 010), named follow pill (spec 009) and avatar.
