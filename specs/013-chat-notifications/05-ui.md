## Deviations from the mockup

- The bell sits in a slim bar under the header (or at the top of the room when the header is hidden) rather than inside the header.
- Unread dot is built on the post page chat preview only. Feed cards and the nav have no dot yet (a per-card lookup would cost a query per card on the feed).
- Direct messages get mute and global-preference handling but are not collapsed: each DM still notifies.
- Notification rows reuse the existing notification list styling (no per-kind icons).

## New patterns proposed

- Three-level notification sheet (bell with state). Candidate for the pattern library at Freeze.
