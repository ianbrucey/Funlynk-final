## Deviations from the mockup

- The day-before Confirm and Release buttons live on the event page next to the item ("Still bringing it" and "Release"), not inside the notification row. The notification opens the event at the list.
- "Mark brought" shows only when an item has claims.
- The "someone took the last one" case shows as an error toast from the server rather than a separate screen.

## New patterns proposed

- Item row with a derived status badge and a primary claim action. Candidate for the pattern library at Freeze.
