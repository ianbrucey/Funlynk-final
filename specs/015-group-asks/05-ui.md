- [x] validation error (link not allowed, amounts, missing proof, missing reasons; typed values are kept)
- [x] denied (visitors get no propose, record or chip buttons; non-admins get no approve, record, void or close)
- [x] conflict (n/a: entries are append-only)
- [x] success (toasts for every action)
- [x] destructive-action confirmation (void needs a reason, close needs a note, decline needs a reason)

## Deviations from the mockup

- Sheets are simple overlays, not animated bottom sheets.
- The ask list is one flat list per section with no skeleton loading state (the tab loads in one query).
- Photos are chosen with the browser's file picker; there is no thumbnail preview before saving.
- Not browser-tested yet. Check at 390px.

## New patterns proposed

- Ledger rows with struck-through voided entries and proof thumbnails. Candidate for the pattern library at Freeze.
