## Screen → component map

| Mockup section | Blade / Livewire component | New or existing |
|---|---|---|
| Search icon in the chat header | `livewire/chat/chat-component.blade.php` header | existing — small addition |
| Search bar, results list, "Show more" | same component; new `searchQuery`, `searchResults`, `searchPage` state | existing — extended |
| Jump to an old message, "Back to latest" | `ChatComponent::jumpTo()` and `ChatService::getMessagesAround()` | existing — extended |

- [x] denied (non-participants never reach the component; server re-checks `view`)

## Deviations from the mockup

- The search bar sits under the existing notification row, and the search icon sits beside the bell, not in the title header (the header is hidden on some pages).
- The jumped-to message flashes with the existing cyan highlight, not the mockup's outline.
- "Back to latest" sits in a bar under the thread, not floating over it.
- Not browser-tested yet. Check at 390px.

## New patterns proposed

- Search result row with highlighted match. Candidate for the pattern library at Freeze.
